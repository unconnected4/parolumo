## Tried and rejected
- Starting backend-first with database schema and auth: Rejected in favor of outside-in UI prototyping, as designing the user-facing cards and search views first dictates the exact API contract and avoids premature schema assumptions.
- Partial unique index on active cards (`WHERE deleted_at IS NULL`): Rejected per ClaudeC-Opus5.5 P1 review. It would create duplicate historical rows for the same sense and orphan previous review logs. Restoring existing cards under a single unique constraint `(user_id, sense_id)` is cleaner.
- Hand-writing TS mapping for MSW fixtures: Rejected per P5. Duplicating the Yandex mapping in TypeScript causes contract drift. Generating API examples from the Python backend mapping keeps a single source of truth.
- Hand-drafting `docs/api/openapi.json`: Rejected per P6. Exporting directly from FastAPI schemas maintains the spec's single source of truth.

## Decisions made during this task
- **Build order**: Step 0 contract & fixture slice + outside-in UI prototyping before backend persistence layer. Promoted to root `intent.md`.
- **Card restoration (P1, P9)**: Re-saving a deleted sense restores the existing card (`deleted_at = NULL`), keeping its existing copied sense data, notes, custom examples, and FSRS state intact. Single unique constraint on `(user_id, sense_id)`. Active card filtering is centralized in `services/cards.py`.
- **Backend slice for fixtures & contract (P5, P6)**: Step 0 implements Pydantic schemas, Yandex mapping, `fake` provider, and stub routes to export `docs/api/openapi.json` and `docs/api/examples/`.
- **Fixture boundaries (P7)**: Raw provider responses in `backend/tests/fixtures/yandex/<word>.json`. Generated API response examples in `docs/api/examples/<endpoint>/<case>.json`. `web/` MSW mocks consume only from `docs/api/examples/`.
- **Yandex key fallback (P8)**: If key registration is delayed, Step 0 uses documented sample responses from Yandex API docs. If no key can ever be obtained, escalate `DictionaryProvider` swap.
- **Cache role (P4)**: `lookup_cache` is defined strictly as a deduplicating cache with TTL; rate limiting/throttling is a distinct concern.
- **Styling**: Tailwind CSS for web SPA.
- **Auth transport**: Use `fastapi-users` dual transports (`CookieTransport` for web, `BearerTransport` for mobile).
- **Pronunciation**: Client-side `window.speechSynthesis` (Web Speech API) provides zero-cost audio playback, with feature detection to hide when unsupported.
